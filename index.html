Über mich

Ich bin Leon, Schüler, und beschäftige mich in meiner Freizeit mit Webentwicklung. Angefangen hat es mit Neugier: Wie funktioniert eine Website eigentlich von innen? Aus der Frage sind ein paar Projekte geworden — und die Erkenntnis, dass ich das Bauen tatsächlich gerne mache.

Am liebsten arbeite ich an Sachen, die man sofort sieht: Layouts, Animationen, kleine Interaktionen, die sich gut anfühlen. Frameworks schaue ich mir gerade an, aber ich will vorher verstehen, was darunter passiert.

HTML CSS JavaScript Git GitHub Pages UI-Design

Was mich antreibt

  • Dinge selbst bauen statt nur nachzumachen
  • Verstehen, warum etwas funktioniert
  • Design, das nicht nur hübsch, sondern benutzbar ist
  • Sauberer Code, den man in einem Jahr noch liest

Woran ich gerade arbeite

  • JavaScript sicherer beherrschen
  • Erste Schritte mit einem Framework
  • Barrierefreiheit ernst nehmen
  • Mehr eigene Projekte veröffentlichen
